# Rename audit: "SSH Manager" → Ophion

Every place the old name or its forms appear, classified before anything was
changed (baseline commit `b4a4aeb`). Search used:
`git grep -nIE "ssh[-_ ]?manager|sshm|SSHManager|SSH_MANAGER|org\.codex"`.
Counts cover the whole repository (code, tests, docs, packaging);
`tests/fixtures/pre_rename/` is excluded. That folder holds files the old
version wrote, and they must stay as they are.

The names now live in `ophion/identity.py` (`APP_NAME`, `APP_SLUG`,
`APP_ID`, `APP_TAGLINE` and the `LEGACY_*` names).

## Classes

- **U**: user-visible text. Renamed to Ophion.
- **E**: external identifier (directory, command, app id, desktop file, MIME
  type, environment variable). Renamed, with a migration or fallback.
- **C**: cryptographic, format or schema constant. **Kept**; changing it would
  make existing data unreadable.
- **L**: legacy name needed to read old data or to reach old secrets. **Kept**.
- **I**: internal identifier (package, module, class, test, CSS or icon
  name). **Kept**.

## Verification

- `tests/test_pre_rename_fixtures.py` opens files written by the old version:
  keybox, secrets, macros, plain and encrypted `.sshm` exports, and the old
  OpenSSH export and `Include` marker.
- `tests/test_rename_guard.py` fails when `org.codex.SSHManager` or an
  `ssh-manager` path literal appears in `ophion/**/*.py` outside
  `identity.py`, `legacy_paths.py` and `tests/rename_allowlist.txt`. Each
  allowlist entry gives its reason and its row in this table.
