# Application icon (`ophion`)

- **Artwork:** the spiral mark (orange, cream, dark green) on a transparent background. No tile.
- **Source:** generated by `tools/prepare_ophion_icon.py` from `data/icons/source/SOURCE_ORIGINAL_UNMODIFIED.png`
  (crop + resample only; see `data/icons/README.md`). Do not edit these files by hand: change the
  script and run it again.
- **Sizes:** 16, 22, 24, 32, 48, 64, 96, 128, 256, 512 px, in the hicolor layout. This lets the folder join
  the GTK icon theme search path (`gtkui/widgets/icons.py: install_app_icon`), and the packaging copies it
  to `share/icons/hicolor`. The mark fills 87–92 % of each square, centred.
- **Raster only, no SVG.** Sizes above 1024 px need a vector redraw of the artwork.
